Life Sciences - Change Control

Request, assess, approve, implement and verify changes in a regulated environment

What the module does

The module manages the complete lifecycle of a change in a pharmaceutical, medical device, medical plastics, cosmetics or laboratory organisation: Draft, Under Review, Impact Assessment, Approved, Implementation, Verified, Closed, with Rejected and Cancelled as final outcomes.

Main features

  • Change categories driving the impact areas to assess, the approval matrix and the deadlines.
  • One impact assessment record per impact area, so that assessment coverage is deterministic.
  • Approval matrix generated from the category, with the identity, the date and time in UTC and the meaning of each decision recorded.
  • Implementation actions requiring an evidence reference before they can be closed.
  • Effectiveness verification with acceptance criteria defined before the verification is performed.
  • Change control record report, printable for an inspection.
  • Three scheduled reminders: pending approvals, late implementations, due verifications.

Data integrity

  • The description of the change is frozen as soon as the request is submitted.
  • Workflow fields are only written by the workflow methods.
  • Completed assessments, recorded decisions, closed actions and completed verifications are immutable.
  • A submitted change request is never deleted.

Important notice on regulatory compliance

This module is designed to support the implementation of change control processes. Software alone does not achieve regulatory compliance. Compliance depends on the procedures of the organisation, the validation of the system in its intended use, the training of personnel and the quality management system. The module is not certified against any regulatory framework.
