Life Sciences — Training Management

Training, certification and competency management for regulated environments

Pharmaceutical manufacturing · Medical devices · Medical plastics · Cosmetics · Laboratories

Please read before installing

This release has never been installed or executed. It was developed without access to an Odoo 19 runtime. Five API assumptions are documented as unverified in doc/verification_notes.md, together with their remediation. Install on a scratch database and run the test suite first.

Controlled course catalogue

Courses follow an explicit approval lifecycle — Draft, Under Review, Approved, Obsolete — because training must be delivered against controlled material. Only approved courses can be scheduled.

Each course is versioned. The version in force at the moment a certification is issued is copied onto that certification and never changes, so a later revision cannot retroactively alter what an employee was trained on.

  • Classroom, on-the-job, self-study, external e-Learning
  • Configurable certification validity
  • Optional assessment with a pass mark
  • Competencies granted by the course

Outcomes derived from evidence

A trainer records presence and, where required, a score. The system derives pass or fail. Nobody can type a result directly, so any outcome can be reconstructed from its inputs — which is exactly what an auditor does during a data-integrity review.

Absence yields Pending, not Failed, because non-attendance is not a failed assessment.

Append-only certifications

  • Issued automatically when a session closes
  • Recorded manually for external training
  • Never deletable — revocation with a documented reason is the only withdrawal path
  • Renewal adds a record; history is never overwritten

Status is computed from the expiry date and refreshed nightly, so a lapsed qualification never continues to display as valid. Employees are emailed inside a configurable warning window.

Requirements and the training matrix

State that a job position, a department or a named employee must hold a course. The matrix then reports every employee/course cell as Valid, Expiring Soon, Expired, Revoked or Not Trained, with a one-click Gaps filter and a pivot view.

Each employee carries a compliance rate, and a one-page individual training record can be printed for inspection.

Regulatory position

This module supports implementation of training and competence processes of the kind expected by ISO 9001:2015, ISO 13485:2016, GMP guidance, ISO 22716:2007, ISO 15378:2017 and FDA 21 CFR Part 211.

It does not implement FDA 21 CFR Part 11. There is no electronic signature and no field-level audit trail. It implements nothing ANPP-specific, because ANPP training-record requirements could not be verified from official sources.

Software does not deliver compliance. Compliance is produced by an organisation's procedures, its trained personnel, its quality system and its own validation of the tools it uses.
