Life Sciences — Medical Plastics

Injection moulding execution records, tool register and material traceability for medical plastics and pharmaceutical primary packaging.

Moulding Runs

Each moulding campaign is recorded end to end: setup against an approved parameter specification, start-up verification, in-process readings, material lots consumed and rejects by reason and cavity. Closing a run freezes it permanently and advances the tool shot counter.

Append-Only Readings

Parameter readings cannot be edited or deleted. A wrong value is corrected by capturing a new reading that supersedes it and states the reason, so the original entry remains visible in the record. Each reading freezes the acceptance criteria in force at the moment of capture.

Tool and Cavity Register

Moulds carry a lifecycle state, a per-cavity register, cumulative shot counting derived from closed runs, and dual preventive maintenance scheduling on shots and on elapsed months. Individual cavities can be blocked without withdrawing the whole tool from service.

Segregation of Duties

The author of a moulding parameter specification may neither review nor approve it, and the reviewer may not approve it. The operator or setter of a run may not review that run. These rules are enforced at ORM level, not only in the user interface.

Scope Statement

This module supports the implementation of processes used in regulated medical plastics manufacturing. It does not certify compliance with any regulatory framework. It does not implement electronic signatures, deviation management or document control; the identities it records are Odoo user accounts. Validation of the installed system remains the responsibility of the operating organisation.
